## 一、背景介绍

本毕业论文当前已进入定稿阶段，正文版本为 `docs/论文工作区/基于容器的云文件管理系统设计与实现-降AI提重-v8-20260522.docx`。指导老师在评阅过程中明确指出：当前论文中的流程图和结构图过于"花里胡哨"，与西安邮电大学网络工程专业的常规毕业论文样式不一致，存在以下问题：

1. 配色过多、彩色填充与渐变过重，打印后辨识度低；
2. 图标（电脑/盾牌/钥匙等装饰图形）过多，偏离工程论文风格；
3. 连线存在斜线、曲线、彩色泳道带，不符合"箭头保持很直、简洁明了"的要求；
4. 图标题编号风格（`图 3-1`）与西邮样文（`图 3.1`）不一致；
5. 文字字号偏小，打印后部分小字难以看清。

为对齐校内样文风格，已选取 2020 级网络工程专业柯玫同学的毕业论文（`docs/参考资料/毕业论文_网络2002班_04202067_柯玫.docx`）作为格式样本，并提取其样式骨架与流程图原图作为参照。柯玫论文的流程图与结构图特征如下：

- 整图为**纯白底**；
- 节点统一使用**黑色细边框 + 白色填充**，无渐变、无阴影、无立体效果；
- 所有连线为**黑色细直线箭头**，全程**正交走线**（仅水平或垂直，转角直角）；
- 判定菱形分支线上用文字"是 / 否"标注；
- 不出现彩色图标、emoji、装饰条、泳道彩带；
- 图标题编号格式：`图 3.1  系统登录流程`（编号用点号，编号与标题之间两个半角空格）；
- 图标题字号：五号（约 11 pt）、宋体、居中。

本文件给出两部分内容：

- 第二节：柯玫论文样式骨架（用于后续 docx 格式调整，不影响生图）；
- 第三节：需要重画与新增的图清单 + 9 段独立可用的生图提示词（每段都内嵌通用风格规范，可直接投喂给生图智能体）。

系统截图（登录页、文件列表、上传页、回收站、Docker Compose 运行结果等）由本人在实际部署的系统上自行截取，不在生图任务范围内。

## 二、柯玫论文样式骨架（格式调整参考）

### 2.1 实测样式表

| 元素 | 字体（中文 / 英文） | 字号 | 对齐 | 备注 |
|---|---|---|---|---|
| 一级标题（"摘 要 / 目 录 / 第 X 章 / 结 论 / 参考文献 / 致 谢"） | 黑体 SimHei | 15 pt | 居中 | 标题文字内部带空格做字符间距，例如 `摘    要`、`结    论`、`致    谢` |
| 二级标题（如 `2.1 相关技术`） | 黑体 | 小四（12 pt） | 左对齐 | 编号与标题之间两个半角空格 |
| 三级标题（如 `2.1.3 Spring Boot`） | 黑体 | 小四（12 pt） | 左对齐 | 编号与标题之间两个半角空格 |
| 正文段落 | 宋体 / Times New Roman | 小四（12 pt） | 两端对齐 | 首行缩进 2 字符 |
| 图标题 | 宋体 | 五号（11 pt） | 居中 | 格式 `图 3.1  系统登录流程`，置于图下方 |
| 表标题 | 宋体 | 五号（11 pt） | 居中 | 格式 `表 X.Y  ××表`，置于表上方 |

### 2.2 当前 v8 论文的格式问题清单

1. 图编号格式不统一：现为 `图 3-1`、`图 4-1`，需统一改为 `图 3.1`、`图 4.1`（点号）；
2. 一级章节标题部分缺少字间距空格（如"摘要"应为"摘&nbsp;&nbsp;&nbsp;&nbsp;要"）；
3. 部分正文首行缩进使用空格凑出，需统一改为段落属性级首行缩进 2 字符；
4. 章节编号后空格类型不统一（半角 / 全角混用）；
5. 全文章节字体字号需统一为：一级 15 pt 黑体居中，二三级小四黑体左对齐。

> 上述格式调整不影响图，可在生图完成后再行处理。

## 四、使用建议

1. 先丢提示词 ⑥（图 4.1 登录流程）作为试金石，验证生图智能体是否正确遵守"纯黑白 + 正交直线 + 无图标"约束；
2. 验证通过后，按 ① ~ ⑨ 顺序批量出图；
3. 出图回收时，优先检查：
   - 是否出现彩色或渐变；
   - 是否存在斜线 / 曲线；
   - 文字是否被压扁、是否能在 A4 打印件上看清；
   - 图标题文本是否使用 `图 X.Y` 点号格式（生图阶段标题可作为图内或图外文字处理，最终插入论文时再统一）；
4. 不通过则单图重出，不需要重跑全部。
