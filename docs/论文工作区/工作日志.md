## 🔧 新增功能原理说明

### JWT 认证原理
```
登录流程：
用户名+密码 → 后端验证(BCrypt) → 生成JWT Token → 返回前端
                                                    ↓
后续请求：                                      存储localStorage
前端请求 → Header携带token → 后端拦截器验证 → 放行/拒绝
```

### 文件分享原理
```
创建分享：
选择文件 → 设置有效期 → 生成8位分享码 → 存入数据库 → 返回分享链接

访问分享：
分享链接 → 提取分享码 → 查询数据库 → 验证有效期 → 返回文件下载链接
```
