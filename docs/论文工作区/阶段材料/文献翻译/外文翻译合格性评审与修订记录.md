## 一、评审标准（按学校常规要求归纳）

1. **选题相关性**：外文文献必须与毕业设计课题密切相关。
2. **字数要求**：英文原文连续节选不少于 3000 词；中文译文与之对应。
3. **完整性**：包含文献题录、原文节选、对应中文译文、参考文献条目。
4. **结构对照**：原文与译文章节、段落必须一一对应，不得跳译、漏译。
5. **术语规范**：关键技术术语翻译统一，首次出现处给出英文括注。
6. **引文与图表标识**：引用、图表标号要在译文中保留，便于核对。
7. **译者声明**：注明译者、翻译范围、翻译策略、用途。
