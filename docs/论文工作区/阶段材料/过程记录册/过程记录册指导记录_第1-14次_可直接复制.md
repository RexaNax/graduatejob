## 第1次指导记录

**本次指导内容**：在开题后进一步明确毕业设计题目与研究主线，要求围绕“基于容器的云文件管理系统设计与实现”开展后续工作，先完成文献查阅、开题报告修改准备和项目整体技术路线梳理。指导过程中强调系统不应只停留在普通文件管理功能实现上，还应突出容器化部署这一课题特色，并提前规划后续论文写作与系统实现之间的对应关系。  
**学生完成情况**：已结合现有项目基础梳理系统目标，初步确定采用 Vue 3、Spring Boot、MySQL、Redis、Docker Compose 与 Nginx 作为整体技术路线；同时开始整理开题报告初稿内容，明确论文研究对象为云文件管理系统的设计、实现与容器化部署。  
**存在问题与改进**：当前对论文主线与系统边界的理解还不够稳定，容易把文件管理功能与平台化能力混写。后续需要进一步收敛课题范围，确保题目、系统实现和论文口径保持一致。  
**下一步计划**：继续修改开题报告，补充相关文献，细化系统模块划分，并形成较明确的实施进度安排。
