## 四、问题排查命令

如果出问题，执行以下命令获取信息：

```cmd
# 查看容器状态
docker compose ps

# 查看后端日志
docker compose logs backend

# 查看数据库日志
docker compose logs mysql

# 查看 Nginx 日志
docker compose logs nginx

# 检查 MySQL 健康状态
docker inspect lfs-mysql --format='{{.State.Health.Status}}'
```
