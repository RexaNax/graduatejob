# FFmpeg 转码功能测试方案

## 一、转码功能概述

### 1.1 技术实现

本系统使用 **JAVE2**（Java Audio Video Encoder）库封装 FFmpeg，实现：

| 功能 | 说明 | 核心类 |
|------|------|--------|
| 视频转 MP4 | 支持分辨率/码率/帧率配置 | `VideoService.transcode()` |
| 视频转 HLS | M3U8 分片，每片 10 秒 | `VideoService.video2hls()` |
| 视频封面截取 | 自动截取多帧作为封面 | `VideoService.videoCreateThum()` |
| 视频水印 | 支持四角定位 | `VideoUtil.setWatermark()` |
| 文档转 PDF | Word/Excel/PPT 转换 | `DocumentService.transcode()` |

### 1.2 转码模板参数

| 参数 | 可选值 | 默认值 |
|------|--------|--------|
| 输出格式 | mp4, m3u8 | mp4 |
| 视频编码 | h264 | h264 |
| 帧率 | 15, 20, 25, 30, 40, 50, 60 | 30 |
| 视频码率 | 500, 800, 1200, 2000, 3000, 5000, 8000 kbps | 2000 |
| 音频编码 | aac | aac |
| 音频码率 | 16-512 kbps | 128 |
| 音频采样率 | 8000-96000 Hz | 44100 |

## 二、测试环境准备

### 2.1 准备测试视频

建议准备以下规格的测试视频：

| 编号 | 规格 | 时长 | 预估大小 | 获取方式 |
|------|------|------|----------|----------|
| V1 | 720p 30fps | 30秒 | ~15MB | 手机录制或下载样片 |
| V2 | 1080p 30fps | 3分钟 | ~100MB | 下载样片 |
| V3 | 1080p 60fps | 5分钟 | ~200MB | 下载样片（可选） |

**免费样片下载**：
- https://sample-videos.com/
- https://www.pexels.com/videos/

### 2.2 启动测试环境

```bash
# Win11 环境
cd C:\yjxbishe\project\deploy
docker compose up -d

# 查看后端日志（观察转码过程）
docker compose logs -f backend
```

### 2.3 配置转码模板

1. 登录系统：http://localhost（admin/123456）
2. 进入「转码模板」页面
3. 创建测试模板：

| 模板名称 | 格式 | 分辨率 | 码率 | 用途 |
|----------|------|--------|------|------|
| 标清压缩 | mp4 | 480p | 800kbps | 测试压缩效果 |
| 高清保持 | mp4 | 1080p | 3000kbps | 测试高质量转码 |
| HLS分片 | m3u8 | 720p | 2000kbps | 测试流媒体分片 |

## 三、测试用例

### 3.1 基础功能测试

#### TC-01：视频上传自动转码

| 项目 | 内容 |
|------|------|
| **前置条件** | 已创建转码模板，系统正常运行 |
| **操作步骤** | 1. 上传 V1 测试视频<br>2. 观察「转码进度」页面 |
| **预期结果** | 1. 上传成功后自动触发转码<br>2. 进度实时更新<br>3. 转码完成后生成新文件 |
| **检查点** | □ 转码进度显示正确<br>□ 转码后文件可正常播放<br>□ 文件大小符合预期 |

#### TC-02：视频封面自动生成

| 项目 | 内容 |
|------|------|
| **前置条件** | 上传视频文件 |
| **操作步骤** | 1. 上传视频<br>2. 查看文件列表 |
| **预期结果** | 视频文件显示封面缩略图 |
| **检查点** | □ 封面图片正常显示<br>□ 封面内容为视频截图 |

#### TC-03：HLS 分片转码

| 项目 | 内容 |
|------|------|
| **前置条件** | 创建 m3u8 格式转码模板 |
| **操作步骤** | 1. 上传视频<br>2. 使用 HLS 模板转码<br>3. 在线播放 |
| **预期结果** | 1. 生成 .m3u8 索引文件<br>2. 生成多个 .ts 分片文件<br>3. 播放器支持进度拖拽 |
| **检查点** | □ 分片文件数量 = 视频秒数 / 10（向上取整）<br>□ 播放流畅无卡顿 |

#### TC-04：视频水印功能

| 项目 | 内容 |
|------|------|
| **前置条件** | application.yml 中 `video.watermark.enable: true` |
| **操作步骤** | 1. 上传视频<br>2. 转码完成后播放 |
| **预期结果** | 视频左上角（或配置位置）显示水印图片 |
| **检查点** | □ 水印位置正确<br>□ 水印透明度适中<br>□ 不影响视频内容观看 |

#### TC-05：手动重新转码

| 项目 | 内容 |
|------|------|
| **前置条件** | 已有转码完成的视频 |
| **操作步骤** | 1. 修改转码模板参数<br>2. 点击「重新转码」 |
| **预期结果** | 使用新参数重新转码 |
| **检查点** | □ 旧转码文件被清理<br>□ 新转码文件参数正确 |
