# 目录说明

本文档用于说明当前仓库中各级有用目录和关键文件的用途，方便项目开发、论文写作、代码验收和后续接手时快速定位。

## 仓库根目录

- `project/`
  - 当前项目主代码目录，包含前端、后端和部署配置。
- `docs/`
  - 项目资料、论文工作区、参考资料和辅助说明文档的集中目录。
- `archive/`
  - 历史归档目录，保存旧版本入口、旧阶段材料和已下线内容。
- `提交材料/`
  - 面向代码验收、论文答辩等正式提交场景整理的材料目录。
- `README.md`
  - GitHub 仓库首页说明文件，简介项目背景、功能、技术栈和启动方式。
- `01_项目入口.md`
  - 项目开发与代码验收场景的快速入口说明。
- `02_论文入口.md`
  - 论文写作与答辩材料整理场景的快速入口说明。

## project

- `project/frontend/`
  - 前端工程目录，基于 Vue 3、Vite、Element Plus。
- `project/backend/`
  - 后端工程目录，基于 Spring Boot 3、MyBatis-Plus、MySQL、Redis。
- `project/deploy/`
  - 部署目录，包含 Docker Compose 配置、Nginx 配置和部署脚本。
- `project/README_课程设计收尾说明.md`
  - 当前项目收尾说明，适合演示、验收前快速回顾系统现状和默认账号。

## project/frontend

- `src/`
  - 前端核心源码目录。
- `public/`
  - 前端静态资源目录。
- `dist/`
  - 前端生产构建输出目录，供 Nginx 直接挂载使用。
- `node_modules/`
  - 前端依赖目录，本地开发使用，不纳入 Git 管理。
- `package.json`
  - 前端依赖与脚本入口。
- `vite.config.js`
  - 前端构建配置文件。

## project/backend

- `src/`
  - 后端核心源码目录。
- `sql/`
  - 数据库初始化与补丁脚本目录。
- `imgs/`
  - 后端相关流程图和说明图片资源。
- `target/`
  - 后端构建输出目录，本地编译产物，不纳入 Git 管理。
- `logs/`
  - 后端运行日志目录。
- `pom.xml`
  - Maven 项目配置文件。
- `Dockerfile`
  - 后端镜像构建文件。

## project/deploy

- `docker-compose.yml`
  - 项目整体容器化部署入口。
- `nginx/`
  - Nginx 配置目录，用于前端静态资源服务与接口转发。
- `deploy.sh`
  - 部署辅助脚本。

## docs

- `docs/项目资料/`
  - 当前项目事实资料、上下文、部署与测试辅助说明。
- `docs/论文工作区/`

- `docs/参考资料/`

- `docs/superpowers/`

## archive

- 主要存放旧入口、旧上下文、旧阶段草稿和历史归档内容。
- 除非需要回看历史版本，否则不建议作为当前工作的优先读取目录。
