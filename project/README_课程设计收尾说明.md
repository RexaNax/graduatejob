## 当前可用账号

- `admin / 123456`
  - 管理员账号
  - 可查看和管理全部文件数据
- `demo / 123456`
  - 演示账号
  - 只能查看和管理自己的文件空间

## 演示建议

1. 先用 `admin` 登录，展示历史文件与完整数据。
2. 再用 `demo` 登录，展示根目录为空或仅有自己数据。
3. 分别创建两个测试目录，证明相互隔离。
4. 打开 `06_封面图.png` 预览，展示预览已修复。
5. 打开容量统计，说明普通用户看到的是个人空间数据。
